D-cut — building and running on Arch Linux
==========================================

Requirements: Rust via rustup (toolchain pinned in rust-toolchain.toml), base-devel,
alsa-lib, a Vulkan driver (mesa / vulkan-radeon), ffmpeg (provides ffprobe).

From the project directory:
  cargo run --release -p editor-ui -- [video files or project.dcut]
  cargo test --workspace -j 2

AppImage:
  scripts/build-appimage.sh          # needs Podman, or Docker with socket access
  scripts/build-appimage.sh --host   # no container; only runs on glibc >= this machine's
  ./build/appimage/D-cut-x86_64.AppImage
  ./build/appimage/D-cut-x86_64.AppImage --appimage-extract-and-run   # without FUSE

The AppImage does not bundle FFmpeg yet: install ffmpeg on the host.
